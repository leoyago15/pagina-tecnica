Términos y Condiciones de Servicio

Última actualización: Noviembre de 2026

1. Aceptación de los términos

Al acceder y utilizar el Dashboard IT y sus servicios de notificaciones, el usuario (personal técnico o administrativo) acepta cumplir con estos términos. El acceso está restringido únicamente a usuarios autorizados por la institución.

2. Uso del servicio

La plataforma y sus agentes de auditoría deben utilizarse exclusivamente para la gestión de infraestructura tecnológica de los laboratorios escolares. Queda estrictamente prohibido intentar vulnerar la seguridad del dashboard o utilizar el servicio de mensajería asociado para enviar contenido no relacionado con alertas de sistema.

3. Modificaciones de hardware y software

El sistema reportará automáticamente cualquier alteración no autorizada en el hardware (como sustracción de componentes) o instalación de software no permitido en las estaciones de trabajo monitoreadas.

4. Disponibilidad

El servicio se ofrece "tal cual" para fines internos de administración. Aunque nos esforzamos por mantener el servicio operativo, pueden ocurrir interrupciones por mantenimiento del VPS o actualizaciones del sistema.
